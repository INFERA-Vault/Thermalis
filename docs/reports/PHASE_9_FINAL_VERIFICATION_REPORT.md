## 4. Validation Methodology
Due to geographical clustering, `StratifiedKFold` (randomly shuffled 5 folds preserving class percentage) was utilized instead of group-aware block validation. 

## 5. Geographic Limitation
An independent check confirmed a hard physical limitation:
- 100% of the agricultural class (91 instances) is strictly contained in a single 50km geographic block (`30.0_75.5` in Punjab).
- Because a GroupKFold holdout would starve the fold of the entire negative class, a valid stratified group split is mathematically impossible without breaking the binary model. Stratified evaluation effectively gauges structural signal but does not strictly prove broad geographic generalization to unseen climates.
